# Usage guide

The usage documentation is organized by workflow:

1. [Install the environment and base components](installation.md).
2. [Prepare and validate the restoration weights](models.md).
3. [Restore images or launch the demo](inference.md).
4. [Train using paired images](training.md).
5. [Evaluate and record reproduction settings](evaluation.md).

See [Reproducibility](reproducibility.md) for checks actually executed and [Known issues](issues.md) for observed failures and fixes.
